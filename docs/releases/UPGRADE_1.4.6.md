# 1.4.6 升级说明

## 总览界面与指标

- 总览主卡改为炭灰底色，放大年度预计分红金额，并显示当前筛选范围内最早一笔买入至今的时间。
- 首页提供 12 种可选指标，默认选择成本息率、市值息率、浮动盈亏、净投入、持仓只数和盈亏率。用户可选择 0–6 项、保存或恢复默认；设为 0 项时隐藏指标栅格。选择保存在本地应用设置中。
- 可选项还包括今年已收、总成本、总市值、月均/日均预测分红和累计收息。金额按币种分列，不做外币换算；净投入按买入成交额（含手续费）减卖出净额汇总。浮动盈亏和市值息率只采用有行情的持仓，行情缺失时不把浮盈写作 0；总市值仍按现有规则对无行情持仓以成本估值。

## 日历控件微调

- 月历/年度总览切换卡仅保留两个视图选项；移除“日历说明”入口及日历页内重复的账户范围提示。
- 全局账户筛选继续由总览控制，月历和年度总览仍按当前账户范围查询；持仓页账户范围提示保持不变。
- 分段选中项的圆角按浅金轨道半径扣除内边距，修正下沿圆角不贴合的问题。
- 月份/年份左右导航与“回到今天/今年”使用一致的轻量透明样式，保留可访问名称和至少 48dp 点击区域。

## 兼容性与验证

- 应用版本递增到 `1.4.6`（`versionCode 20`），数据库 schema 仍为 4；指标选择仅写入已有本地设置表，不修改账本记录、账户筛选逻辑、月历/年度业务查询或底部导航。
- 本地静态回归覆盖总览指标选择、保存/恢复、按币种展示、日历视图切换、账户范围延续、控件圆角和导航可访问性；源码检查不替代 Android 设备上的实际渲染验收。
