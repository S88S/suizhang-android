# 穗账 Android 1.4.3-debug

## 版本与兼容性

- `versionCode`: **17**（从 1.4.2 的 16 递增一次）
- `versionName`: `1.4.3-debug`
- Application ID: `cn.suizhang.ledger.debug`
- 最低系统：Android 10 / API 29；目标 API 沿用工程设置。
- SQLite schema：**3 → 4**。新增持仓 `cost_method`，兼容默认 `weighted_average`；分红新增可空 `received_amount`。
- 数据库升级保留旧持仓成本、旧分红金额与交易流水。旧记录不会被猜成实收金额；切换成本口径时，切换前的交易/分红不回算，当前单位成本作为新起点。
- 包名不变，调试签名沿用已有应用签名，支持按 Android 常规路径覆盖安装。安装前建议从“更多 → 完整备份与恢复”导出 JSON；不要卸载旧版或清除数据。

## 界面与公式

- 月历信息顺序调整为：未来已公告持仓分红提醒 → 月份导航/回到今天 → 登记/除权/派息图例 → 本月待到账概况 → 最近同步时间与公告核对提示 → 日历网格 → 当日/本月事件与操作。
- 保留穗账原有账户范围、月历/年度总览、四栏导航和红色主题；未整体复制参考产品导航或品牌。
- 每持仓可选择**分红摊薄、摊薄成本、加权平均**。买入手续费计入成本；加权平均卖出按现有均价减少成本，并把卖出手续费计入剩余成本；两种摊薄算法按净卖出回款（成交额减卖出手续费）减少成本。分红摊薄还扣减用户填写的实际净到账金额。
- 持仓补充最近收盘价市值、浮动盈亏、盈亏率、昨收息率、成本息率、同币种内持仓占比、首笔买入至今天数。无行情时市值依参考口径按成本估值，但不计算浮动盈亏并清楚标注；不同币种不直接相加。
- 日历与年度汇总：实收金额优先使用 `received_amount`；未填实收的旧记录仍以原记录金额作为展示口径并提示。税务“未知”不会被当作 0% 或伪装成免税；未知税务状态的持仓不计入税后收入合计。
