# 1.4.7 Excel 账本工作簿与视觉规范升级

## Excel 导入与导出

“更多 → Excel 备份与恢复”现在默认使用标准 `.xlsx` 工作簿，不再要求用户编辑 JSON。导出的文件包含“使用说明”页，以及“账户、持仓、分红、交易、支出目标、标的索引、本地设置”七张数据表。每张表使用中文列名、冻结表头和筛选；ID/关联 ID 列保留原值并标明不要改动。金额和数量以数值单元格导出，证券代码、文字和日期保持文本，避免代码前导零或精度被 Excel 自动改写。

用户可在 Excel、WPS 或 LibreOffice 中查看、筛选和编辑内容，再选回穗账导入。需保留全部工作表及表头，且不要删除或改写 ID/关联 ID；公式工作簿会被拒绝，应先复制并粘贴为数值。导入前明确提示将完整替换本机账户、持仓、分红、交易、目标、税率设置和本地索引。恢复仍使用既有备份校验与单一数据库事务；无效文件或关联错误不会替换现有数据。旧版 JSON 仍可导入以兼容历史备份。

工作簿只在用户选择的位置创建或读取；不向网络上传账本、不申请额外权限、不新增第三方 Excel 依赖。导出文件包含个人财务信息，应由用户妥善保管。

## 视觉与系统适配

延续 1.4.6 的原创暖麦金/暖炭灰品牌视觉、浅深色资源配对、分红优先的信息层级和总览指标布局。按 Material 3 的语义色、对比度、字号与 8dp 间距原则校准，而非复刻小米系统资产。动态壁纸色本版本不覆盖金融方向色；动效克制，以清晰、稳定的数据反馈为先。

已查阅[小米澎湃 OS 开发者文档目录](https://dev.mi.com/xiaomihyperos/documentation)与[小米超级岛官方业务说明](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2140)。超级岛是有独立接入与准入条件的持续服务能力：官方要求生命周期明确且不超过 12 小时，并将长期常驻实时股价列为不适用场景。穗账持仓/分红信息是长期账本，因此本版不接入或仿造超级岛，也不使用小米品牌图形。小米 OS 专属功能如未来确有适用场景，须在目标 OS 版本上按官方 SDK 与审核规范单独评估。

## 兼容与验证

- 版本：`1.4.7-debug`，`versionCode 21`；最低 Android 10/API 29。
- SQLite schema 仍为 4；不改变财务计算、税务假设、行情/分红数据源或权限。
- 检查 Excel 工作表、字段映射、ZIP 文件大小/路径限制、公式拒绝、旧 JSON 兼容和本地全量恢复安全。
- APK 通过 JDK 21、Android SDK Platform 36、Gradle Wrapper 8.13 的 `assembleDebug` 构建；静态回归通过后仍需在真实设备验证文件选择器、Excel/WPS 往返和大字号排版。本轮工作环境没有连接 Android 设备或模拟器。
- GitHub 只同步适合公开的源码和文档，不放入 APK、真实账本、截图、OCR 结果、运行日志或本机凭据。
