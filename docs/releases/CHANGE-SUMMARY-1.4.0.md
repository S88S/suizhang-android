# 穗账 1.4.0-debug 变更摘要

- **持仓代码自动回填**：完整代码输入后防抖查询现有东方财富公开证券搜索；精确匹配才回填名称、市场/类别、币种，并查询现有公开行情。界面显示数据来源、更新时间与在线/本机缓存状态，失败、离线和无精确匹配均可继续手工录入；旧异步结果不能覆盖新代码。
- **ETF/基金识别与行情**：基金/ETF 代码不会被默认 A 股类别过滤，ETF 可复用现有公开行情服务。没有经过验证的基金/ETF 分红接口时，表单明确说明不可用，不将缺少数据当零分红。
- **数量与成本保持手工**：代码和行情不填充持仓数量或每份成本；搜索结果、行情和分红均不能生成数量、成本、交易或已到账记录。
- **东方财富详情数量识别**：限制在交易记录分界线前的摘要区域，结合 OCR 行坐标和字段标签区分“持仓数量/可用数量”、成本价/买入均价/现价；不把历史卖出数量、红利数量作为当前持仓。冲突保持空白并标“待核对”，用户可编辑并手动确认。
- **保持既有约束**：导航、紧凑标题、账户筛选、折叠日历帮助、设计令牌、SQLite schema 3、JSON 备份、权限、签名和金融/税务算法不变；不触碰真实账本数据。
- **验证边界**：15 组离线与专项回归通过，包括原有 12 组、OCR 导入专项、代码回填专项和脱敏真实图像辅助测试。Tesseract 主机端测试不等于 APK 内 ML Kit 真机验收；无 Android 设备，未做真机视觉/安装迁移验收。
